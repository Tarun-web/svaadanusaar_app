Svaadanusaar — Protein Calculation Module

Architecture, file index, business rules, and integration guide — generated after implementation

1. Overview

The protein module implements a two-stage pipeline:

  1. ProteinCalculator — pure calculation, returns the user's long-term physiological protein target based on goal, body weight (or LBM), and medical safety.
  2. ProteinAdaptationService — adaptation logic, determines the current recommended target, manages ramp-up, and gates progression on GI tolerance.
HealthProfile
   ↓
ProteinCalculator   →  ProteinTargetResult  (long-term target)
   ↓
ProteinAdaptationService  →  ProteinAdaptationResult  (current target)
   ↓
MacroCalculator  →  NutritionTarget.proteinGrams  =  currentTargetGrams
   ↓
Meal/Diet Generator  →  Actual foods  →  Protein quality/digestibility
Key distinction:
NutritionTarget.proteinGrams always stores the current adaptation target, not the long-term goal.
The long-term target lives in ProteinAdaptationProfile.longTermTargetGrams.

5. LBM vs Body Weight

  • If bodyFatPercentage is provided and within 0–60%, LBM is used: LBM = weight × (1 − bodyFat%)
  • If absent or out of range, total body weight is used and a BODY_FAT_INVALID_IGNORED warning is emitted.
  • ProteinTargetResult.calculationBasis explicitly records "LBM" or "BODY_WEIGHT".

6. Bioavailability Guarantee

No bioavailability factor is applied in ProteinCalculator.
The calculated target is the dietary protein requirement in grams.
Protein quality and digestibility are evaluated downstream at the food/recipe selection layer.
A bioavailability factor greater than 100% is architecturally impossible in this module.

7. Adaptation Rules (Centralised in ProteinAdaptationService)

Starting Target Formula

gap = longTermTarget − currentProtein

gap ≤ 15 g           → starting = longTerm         (no reduction)
15 < gap ≤ 30 g   → starting = longTerm − 10 g
30 < gap ≤ 50 g   → starting = longTerm − 20 g
gap > 50 g           → starting = longTerm − 25 g

starting target ≥ current intake (floor rule)

If currentProteinGrams == null (unknown), the starting target equals the long-term target and stage is NOT_STARTED.

Progression Gate (all must be true)

  1. Tolerance status == GOOD or UNKNOWN
  2. Days at current target ≥ 7 (configurable via MIN_DAYS_BEFORE_INCREMENT)
  3. Current target < long-term target

Tolerance Handling

Tolerance StatusAction
GOOD / UNKNOWNAllow progression after minimum period
MILD_ISSUESHold target. Emit TOLERANCE_HOLD warning.
SIGNIFICANT_ISSUESHold target. Emit SIGNIFICANT_GI_SYMPTOMS warning. Advise medical review.

10. Integration Guide — How to Use

Initialising protein for a new user

// Build input from HealthProfile
ProteinCalculationInput input = new ProteinCalculationInput(
    personalProfile.getWeightKg(),
    null,                          // bodyFat — populate if available
    fitnessGoalProfile.getPrimaryGoal(),
    hasResistanceTraining(activities),
    resolveWorkoutIntensity(activities),
    resolveTrainingStatus(activities),
    currentNutritionProfile != null
        ? currentNutritionProfile.getCurrentProteinGrams()
        : null,                    // may be null — never invent it
    medicalProfile != null
        ? medicalProfile.getMedicalConditions()
        : null
);

// Calculate
ProteinAdaptationResult result = macroCalculator.calculateProtein(
    healthProfile, input, null);   // null = first time

// Write to NutritionTarget
nutritionTarget.setProteinGrams(
    macroCalculator.resolveNutritionTargetProtein(result));

Daily progression check (scheduled job)

ProteinAdaptationProfile profile = repository
    .findByHealthProfile(healthProfile).orElseThrow();

proteinAdaptationService.incrementDaysAtCurrentTarget(profile);
ProteinAdaptationResult result = proteinAdaptationService.evaluate(profile);

// Update NutritionTarget if target changed
if (targetChanged(result)) {
    nutritionTarget.setProteinGrams(result.currentTargetGrams());
    nutritionTargetRepository.save(nutritionTarget);
}

Recording GI tolerance

proteinAdaptationService.recordTolerance(
    profile, ProteinToleranceStatus.MILD_ISSUES);
